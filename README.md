# POO3_cinema-WEB

[![License](https://img.shields.io/badge/License-MIT-orange.svg)](./LICENSE)

## Descrição
Este é um repositório de estudo desenvolvido com HTML, CSS e JavaScript. O objetivo principal do projeto é demonstrar a aplicação prática do framework Bootstrap na construção de interfaces web.

## Referências e Tecnologias
O desenvolvimento baseou-se na documentação oficial do Bootstrap para a estruturação de containers e grids:
* [Bootstrap Grid/Containers](https://getbootstrap.com/docs/5.3/examples/grid/#containers)

Para o suporte às funcionalidades do Popper, o arquivo foi obtido através do link abaixo e salvo localmente na pasta do projeto:
* [Popper.js Core](https://cdn.jsdelivr.net/npm/@popperjs/core@2.11.8/dist/umd/popper.min.js)

## Pré-requisitos
Para visualizar e editar o projeto, você precisará de:
* Uma IDE (recomendado VS Code).
* Git instalado para clonagem do repositório.
* Extensão **Open Live Server** instalada no VS Code.

## Instalação e Execução
Ao clonar este repositório, você poderá acessar e executar os dados localmente em sua máquina, sem a necessidade de hospedagem externa.

1. Clone o repositório:
bash
git clone https://github.com/Samyr-Dev/POO3_cinema-WEB

2. Abra a pasta do projeto em sua IDE.
3. Utilize a extensão Live Server para rodar o projeto no navegador.
